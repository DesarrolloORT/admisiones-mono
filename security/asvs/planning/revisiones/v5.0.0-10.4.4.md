## Aplicabilidad y alcance

El requisito es propio de un authorization server OAuth. En el alcance inspeccionado, la API expone autenticación propietaria por LDAP, segundo factor, cookies HttpOnly, refresh token y JWT; el frontend consume esas rutas. No se localizó un endpoint OAuth de autorización o token, registro de clientes, metadata de grants, `response_type`, `redirect_uri` ni `grant_type=authorization_code`.

El endpoint propietario `POST /auth/login` recibe credenciales para autenticación LDAP, pero no es el grant OAuth `password` (ROPC): no recibe `grant_type=password`, no está asociado a un `client_id` OAuth ni emite una respuesta de token OAuth. Tampoco se observó implicit flow. El JWT de servicio hacia Inscripciones y Pagos se genera directamente para una llamada saliente; no configura grants por cliente y no convierte a este monorepo en authorization server.

No se evaluaron la API externa de Inscripciones y Pagos, gateway, LDAP, un proveedor de identidad ni rutas de infraestructura fuera del monorepo. Si alguno opera un authorization server para Admisiones, este resultado no lo cubre.

## Resultado por componente y conclusión

- **API:** NOT_APPLICABLE. No se evidenció que opere un authorization server OAuth ni que administre clientes y grants OAuth. Su login propietario no debe clasificarse como ROPC sólo porque recibe una contraseña.
- **Frontend:** NOT_APPLICABLE. Consume rutas propias y no inicia implicit flow, ROPC ni otro grant OAuth.
- **Core:** NOT_APPLICABLE dentro del alcance del inventario; no se localizó componente OAuth/OIDC en la versión fijada.
- **Integración externa:** fuera del alcance de evidencia disponible. El JWT saliente y su documentación no demuestran restricción de grants; no se transfiere este resultado a Inscripciones, Pagos ni a un IdP externo.

La conclusión DOCUMENTADO / NOT_APPLICABLE se limita al monorepo: no hay un authorization server local cuyos grants por cliente puedan verificarse. No se ejecutaron tests, builds, runtime, escaneos ni cambios de código o configuración.
