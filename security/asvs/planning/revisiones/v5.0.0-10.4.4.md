## Aplicabilidad y alcance

El requisito es propio de un authorization server OAuth. En HEAD la API expone autenticación propietaria por LDAP (vía `ORT.Ldap.*`), segundo factor, cookies HttpOnly, refresh token opaco y JWT. No se localizó endpoint OAuth, registro de clientes, metadata de grants, `response_type`, `redirect_uri` ni `grant_type`.

`POST /auth/login` recibe credenciales para LDAP, pero no es el grant OAuth `password` (ROPC): no recibe `grant_type=password`, no está asociado a un `client_id` ni emite una respuesta de token OAuth. Tampoco se observó implicit flow. El JWT de servicio y el acceso a Key Vault con `DefaultAzureCredential` (cliente de Entra ID) no configuran grants por cliente en este monorepo.

No se evaluaron Inscripciones y Pagos, el backoffice, gateway, LDAP ni IdP externos.
