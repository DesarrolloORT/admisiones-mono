## Aplicabilidad y alcance

Incluye login propio, recuperación y establecimiento de contraseña en frontend, API y Core consumido. El boundary relevante es el endpoint público de recuperación, que consulta persona en Oracle y, si coinciden los datos, envía un enlace al correo registrado. El servidor SOAP/LDAP, otras aplicaciones que comparten el directorio, el correo entregado y el despliegue no fueron inspeccionados. Este punto evalúa la presencia de pistas o comprobaciones por conocimiento; la seguridad integral del reseteo corresponde a 6.4.3, reservado para la fase L2.

## Resultado por componente y conclusión

Frontend muestra el campo biográfico y API lo hace obligatorio para decidir si se inicia la entrega del enlace. Eso constituye una comprobación basada en conocimiento dentro del recupero, aunque no sea una «pregunta secreta» elegida previamente ni el único factor para completar el cambio. El requisito prohíbe la presencia de autenticación basada en conocimiento; la condición está explícita y conectada entre UI, contrato y caso de uso. **FAIL** para la implementación propia del recupero. No se halló una pista de contraseña en las superficies examinadas. No se concluye nada sobre las interfaces del proveedor SOAP/LDAP u otros consumidores.

## Hallazgos y propuesta documental

1. **Apellido como comprobación de conocimiento en recuperación.** Condición: se exige acertar el primer apellido del padrón para obtener el envío del enlace. Impacto: se incorpora un dato biográfico relativamente conocible como decisión del ciclo de recuperación, contrario a la ausencia de KBA exigida por este punto; no se demostró un bypass de correo ni toma de cuenta. Evidencia E1-E4. Responsables candidatos: API, frontend y equipo de identidad/producto. Propuesta futura: definir un inicio de recuperación que no dependa de acertar un dato biográfico y conservar verificaciones apropiadas del canal y controles contra abuso; probar no enumeración y entrega solo al canal registrado. No se aplicó fix. No se distribuyó propuesta a otro repositorio: no hay worktree externo vigente verificado; distribución pendiente si se planifica un cambio.
