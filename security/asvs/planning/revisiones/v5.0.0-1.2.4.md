## Aplicabilidad y alcance

- **API incluida:** persistencia Oracle mediante EF Core/Devart, lecturas de personas y tokens, escrituras de entidades y comandos de secuencias; Redis para sesiones, registro y rate limiting. Entradas relevantes: documento/tipo de documento del body HTTP, datos de entidades, hashes/sistema y claves de sesiones. Boundary: request → caso de uso → repositorio → proveedor DB. Desde 260667f6 las entidades de bandeja/workflow (TramiteBandeja, InstanciaWorkflow, Bandeja) pasaron al modelo propio de la API y se consumen mediante el repositorio genérico Devart de la API (commits 3d4ae48b y aa383c67).
- **Core incluido:** únicamente DbConnectionContext, que es el único proyecto Core referenciado por la API ([WebApiAdmisiones.csproj](../../../../api-admisiones/WebApiAdmisiones/WebApiAdmisiones/WebApiAdmisiones.csproj#L43); [Dockerfile](../../../../api-admisiones/WebApiAdmisiones/WebApiAdmisiones/Dockerfile#L13) copia solo esa carpeta). ModBandeja y ModGenericBase siguen en el checkout Core 2ab0254a, pero ya no se compilan ni se consumen desde admisiones (3d4ae48b, be614440).
- **Frontend:** evidencia de la revisión original conservada sin re-verificar: adapter AccountApi usa ApiHttpClient y contratos HTTP; no se encontró motor de consultas local. No se declara NOT_APPLICABLE global.
- Alcance no inspeccionado: comandos realmente emitidos, implementación del proveedor, esquema Oracle desplegado, procedimientos/packages/triggers, API interna de pagos, implementación interna de paquetes ORT.* (incluido ORT.Ldap.Soap) y otros consumidores Core. No se infiere ausencia de procedimientos a partir de búsquedas negativas en el repo.

## Hallazgos y propuesta documental

### H1 — Identificador de secuencia string sin validación en el repositorio genérico (vigente, alcance actualizado)

Condición: [EntityFrameworkRepository.NextId(string)](../../../../api-admisiones/WebApiAdmisiones/DataAccess/DevartDataAccess/DevartRepositories/EntityFrameworkRepository.cs#L74) interpola un string en `SELECT … NEXTVAL FROM DUAL`. Antes no tenía callers productivos en la API; en 912fc665 lo usan los tres llamados de AddCorporateCase (E6), con constantes. Impacto potencial: alterar la estructura SQL si un caller futuro pasa un identificador no confiable; hoy no se confirmó esa ruta. Sin severidad definitiva ni explotación demostrada.

Parte Core: las variantes de ModBandeja/ModGenericBase (E8) dejan de afectar a admisiones porque la API ya no las referencia. Se conservan como observación para otros consumidores de Core, no como hallazgo de este monorepo.

Responsables candidatos: mantenedor del template Devart/API (back-template). Propuesta para fase posterior: restringir a secuencias permitidas mediante enum o allowlist exacta en el template/origen de generación (como ya hace DbConnectionContext), o reemplazar los tres usos por la variante enum de DbConnectionContext si la transacción lo permite. Los identificadores SQL no se resuelven agregando un parámetro de valor. No editar a mano código generado.

Validación futura: pruebas de rechazo de identificadores fuera del conjunto antes de ejecutar comandos, constantes válidas y traducción Oracle.
