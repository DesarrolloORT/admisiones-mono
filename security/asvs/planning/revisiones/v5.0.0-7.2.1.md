## Aplicabilidad y alcance

Se revisaron el JWT de acceso en cookie o Bearer, el refresh token, la sesión temporal de contraseña y el identificador previo al 2FA. La frontera es navegador → API; Oracle y Redis son almacenes backend. El estado Angular controla navegación, mientras la API verifica credenciales en rutas protegidas.

No se inspeccionaron runtime, proxy, configuración efectiva, servicios externos, todos los consumidores de Core ni todas las rutas. Esto limita la conclusión sobre “all”.
