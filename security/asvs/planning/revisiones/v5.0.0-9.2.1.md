# v5.0.0-9.2.1 — vigencia de tokens autocontenidos

## Identificación

- ID: v5.0.0-9.2.1; nivel mínimo L1.

## Aplicabilidad y alcance

Se incluyeron los JWT de acceso recibidos desde cookie HttpOnly o `Authorization`, y los JWT de enlace (propio y de backoffice) y de sesión temporal de contraseña. Estos últimos se validan antes de leer `idSolicitudAlta`, `purpose` y `sub`; el bearer se ejecuta antes de autorización y controladores.

El refresh token es opaco y persistido, no JWT; su vencimiento (ahora acotado al de la sesión original, `73794742`) pertenece a gestión de sesión. El JWT de `TokenServiceInternalApi` es saliente. No se evaluaron gateway/proxy, configuración efectiva, reloj del host, el emisor backoffice ni comportamiento HTTP desplegado.

- Core: sin intervención.
- Emisor backoffice y receptor externo del JWT de servicio: no evaluados.

Resultado global: DOCUMENTADO / NEEDS_REVIEW. Según [ADR-002](../../../adr/ADR-002-asvs-evidence-model.md), lectura estática y tests no ejecutados no habilitan PASS. No se identificó contradicción estática.
