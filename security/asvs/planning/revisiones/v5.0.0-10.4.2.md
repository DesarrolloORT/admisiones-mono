## Identificación

- **ID y nivel mínimo:** v5.0.0-10.4.2 (L1).

For the second valid request with an authorization code that has already been used to issue an access token, the authorization server must reject a token request and revoke any issued tokens related to the authorization code."

## Aplicabilidad y alcance

El requisito exige el canje único sólo cuando existe un authorization server OAuth que retorna authorization codes. La API expone autenticación propia por LDAP, 2FA, cookies HttpOnly, refresh token opaco y JWT; no se encontró en HEAD endpoint de autorización ni token endpoint OAuth, registro de clientes, `response_type=code`, `client_id`, `redirect_uri`, `grant_type=authorization_code` ni dependencias de servidor OAuth/OIDC.

Los códigos 2FA, los enlaces de activación/recupero y el enlace de solicitud aprobada por el backoffice (ADR-030) son flujos propietarios: no se canjean ante un token endpoint por un cliente OAuth. `Azure.Identity` (Key Vault) convierte a la API en cliente OAuth de Entra ID, no en servidor. El JWT de servicio hacia Inscripciones y Pagos sólo se genera.

No se evaluaron Inscripciones y Pagos, el backoffice, gateway, LDAP ni IdP externos.
