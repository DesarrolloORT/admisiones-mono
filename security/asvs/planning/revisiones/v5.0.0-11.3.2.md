## Resultado por componente y conclusión

- **Core: FAIL.** El secreto LDAP se recupera mediante una transformación reversible propia que no es un cifrado ni modo aprobado y no satisface el requisito de utilizar exclusivamente alternativas aprobadas como AES-GCM.
- **API: FAIL por su dependencia de Core.** La API consume el Core que usa esa transformación. El transporte de Pagos no cambia esa conclusión ni permite evaluar el algoritmo del sistema externo.
- **Frontend: NEEDS_REVIEW.** No implementa cifrado propio; sólo transporta el blob de Pagos, cuyo algoritmo y modo no son verificables desde este monorepo.
- **Integraciones externas: NEEDS_REVIEW.** No hay contrato ni evidencia determinística de que `parametrosEncriptados` use un cifrado/modo aprobado.

El resultado global es **FAIL** por la evidencia directa del helper reversible usado para `PasswordLdap`. No se ejecutaron tests, builds, runtime, escaneos ni cambios de código o configuración.

## Hallazgos y propuesta documental

**Hallazgo H1 — protección reversible no aprobada para `PasswordLdap`.** `Encriptador` no aplica un algoritmo ni modo criptográfico aprobado y `Ldap` lo usa para recuperar el secreto LDAP. Impacto: el valor almacenado puede revertirse con el algoritmo y código disponibles, sin las propiedades de un cifrado autenticado moderno. Responsable candidato: Core/API.

Propuesta documental futura: inventariar origen, almacenamiento y consumidores del secreto; migrarlo con compatibilidad controlada a gestión de secretos de plataforma o cifrado autenticado aprobado, como AES-GCM con claves administradas, y validar migración, rotación y rechazo de valores legados. No se aplicó ningún cambio.

**Observación O1 — blob de Pagos sin algoritmo verificable.** API y frontend propagan `parametrosEncriptados` sin conocer el algoritmo o modo. Responsable candidato: integración Inscripciones/Pagos. Propuesta documental futura: solicitar contrato técnico y evidencia de despliegue sin secretos que identifiquen algoritmo, modo, versionado e integridad, seguido de una prueba representativa. No se aplicó ningún cambio.
