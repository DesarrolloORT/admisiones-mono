## Aplicabilidad y alcance

Incluye código C# API y Core consumido, fuente TypeScript y herramientas Node del cliente (evidencia original), Dockerfile y workflows de CI de la API (acotado). Las entradas web son solicitudes JSON y, desde ADR-019 (`90ccee3d`), archivos `multipart/form-data` con `IFormFile`. Los procesos encontrados pertenecen a herramientas de desarrollo/build/CI, con entradas CLI, entorno y datos del repositorio. No se encontró un caller web hacia esas herramientas.

Desde 260667f6 cambiaron las integraciones que procesan documentos: reconocimiento de documentos y caras pasó de Core/AzureService a los paquetes `ORT.DocumentIntelligence.Azure` y `ORT.Vision.Azure` (HTTP a Azure e ImageSharp); LDAP pasó a `ORT.Ldap.Soap`; correo a `ORT.Messaging.ServiceBus` (el render del mail lo hace un worker externo). Se agregó generación de PDF de la declaración jurada con PDFsharp-MigraDoc. No se declara NOT_APPLICABLE global: servicios externos (Azure, LDAP, worker de correo, pagos, Oracle) y dependencias pueden tener procesamiento interno que este repositorio no muestra. Imagen desplegada, binarios transitivos y configuración efectiva del hosting quedan fuera de cobertura.

## Hallazgos y propuesta documental

H1 — `selectAgent` comprueba pertenencia con `in` sobre un objeto con prototipo (frontend/tooling). Sin cambios: no se re-verificó el frontend. Impacto candidato: selección inesperada/error de herramienta local; ejecución OS arbitraria no demostrada. Propuesta: restringir a claves propias de los dos agentes previstos.

H2 — Scanner ejecutable por entorno y wrappers externos no inspeccionados (frontend/plataforma). Sin cambios. Gap de confianza, no vulnerabilidad confirmada. Propuesta: fijar procedencia/ruta del scanner y preservar argv en wrapper PowerShell/Java.
