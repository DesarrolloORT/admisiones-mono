# Fuente OWASP ASVS

La fuente normativa es **OWASP ASVS 5.0.0**, sin modificaciones. El catálogo oficial se publica en [OWASP/ASVS](https://github.com/OWASP/ASVS/tree/v5.0.0/5.0/docs_en). Este repositorio conserva únicamente la selección piloto en `../controls/pilot.json`; las interpretaciones locales están separadas en `../applicability/`.

Formato de ID: `v5.0.0-<requirement>`. No actualizar la versión sin revisar IDs y registrar una ADR.
