# ADR-001 — Security controls as code

## Context
La revisión ASVS dependía de un checklist manual.

## Decision
Versionar un catálogo piloto declarativo, evidencia JSONL y una evaluación determinística en `security/`.

## Alternatives
Continuar con Excel; adoptar una plataforma corporativa completa.

## Consequences
El resultado es reproducible y extensible, pero el catálogo y los mapeos necesitan mantenimiento explícito.
