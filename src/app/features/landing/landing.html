Configuraciones recomendadas (avanzadas)

Sigue estos pasos para configurar a medida tu proyecto

  1. Configura los procesos de DevOps

    En los archivos ubicados en la carpeta .github/workflows se encuentran los flujos de GitHub Actions utilizados en el proceso de CI/CD. Es necesario configurar los runners para algunos flujos.

  2. Configurar repositorio

    Configura el repositorio con branch rulesets para las ramas main y v*.*.*/main (ver Configuración de protección de ramas en el archivo README.md) y configura los secretos y variables de entorno para cada ambiente.

  3. Ver README.md en la sección de pasos recomendados

    Aquí encontrarás una guía de recomendaciones para configurar tu proyecto.

  4. Crear un nuevo README.md

    Reemplaza el contenido de README.md con el de README-template.md y modifícalo para que se adapte a tu proyecto. Luego elimina el archivo README-template.md .
